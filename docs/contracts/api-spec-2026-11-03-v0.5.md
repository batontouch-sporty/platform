### 탈퇴 정리 결과 조회 계약 (PR #144)

- 200 응답은 `{ "sagaId": "...", "requestEventId": "...", "userId": 1, "result": "CLEANED" }` 형태이며 `result`는 `CLEANED`·`REJECTED`·`NONE` 중 하나입니다. user-service는 세 식별 값이 요청 Saga와 일치할 때만 결과를 적용합니다.
- Match는 정리와 같은 회원 잠금을 잡고 `match_db.outbox_event`의 커밋된 결과를 확인합니다. `NONE`은 마감이 지난 뒤에도 결과가 없는 경우에만 반환합니다. 마감 전 결과가 없으면 409, `deadlineAt` 형식 오류는 400, 잠금 대기 초과·DB 오류는 5xx입니다.
- `CLEANED → WITHDRAWN/CLEANED`, `REJECTED → ACTIVE/REJECTED`, `NONE → ACTIVE/TIMED_OUT`. 조회 실패·식별 불일치·알 수 없는 값이면 `WITHDRAWING/PROCESSING`을 유지하고 다음 주기에 다시 조회합니다. 마감 후 정리 자체가 뒤늦게 시작되면 Match는 `DEADLINE_EXCEEDED`로 거절합니다.
- 이미 조회로 `CLEANED`가 확정된 뒤 전달된 동일 Kafka 결과는 정상 중복이며 late CLEANED 경보 대상이 아닙니다. 이벤트 형식은 변경되지 않았습니다. 내부 조회는 Gateway 경유 호출이 아닙니다.

## R10 이후 중요한 판정 조건

1. **생성·참가의 202는 접수입니다.** 보증금 10점 차감이 비동기로 확정되면 `CONFIRMED`; 거절이면 `FAILED`, 취소·만료는 `CANCELLED`가 될 수 있습니다. `GET /match-service/api/matches/requests/{requestId}`로 본인의 현재 요청을 확인하고 포인트 원장과 참가 기록을 대조합니다. 요청 상태에는 `PENDING/CONFIRMED/FAILED/CANCELLED`, 환불 상태에는 `NOT_REQUIRED/PENDING/COMPLETED`가 있습니다. 다른 회원·없는·교체된 예전 requestId는 404입니다.
2. **매치 생성·수정의 정원 최소값은 2입니다.** 1명은 400 `INVALID_INPUT`. 2명 이상이어도 유효 시설·활성 회원·미래 시작·운영시간 등의 조건을 모두 충족해야 합니다. 생성 시 `serviceId`는 시설 DB의 내부 `service.id`이며 서울시 원본 ID가 아닙니다. 시설 스냅샷은 match DB에 복사합니다. 보증금 비활성 설정에서 생성은 과거 방식인 201과 숫자 `matchId`를 반환합니다.
3. **참가 확정 인원만 정원·목록·알림에 포함합니다.** 참가 정지 회원 신규 신청은 403 `PARTICIPATION_SUSPENDED`; 진행 중 같은 요청은 409 `PARTICIPATION_IN_PROGRESS`. 정원 초과는 `MATCH_FULL`, 모집 종료는 `MATCH_RECRUITMENT_CLOSED` 등 상세 페이지의 오류 코드를 사용합니다. 보증금/포인트의 차감·반환 이력은 `DEPOSIT_CHARGED/CANCELLED/RETURNED` 등을 구분합니다.
4. **출석 수정은 별도 API입니다.** 방장이 `startAt <= now < endAt`인 `RECRUITING/CLOSED/IN_PROGRESS` 매치의 `CONFIRMED` 참가 행만 수정합니다. `participantId`는 회원 ID가 아닌 참가 행 ID이며, 성공 204, 시간·상태 불허는 409 `ATTENDANCE_UPDATE_NOT_ALLOWED`입니다. 정산 이벤트는 별도로 처리합니다.
5. **관리자 통계는 누적값입니다.** A28의 `withdrawalSaga.{requested,succeeded,rejected,timedOut,inProgress}`와 `users.{active,withdrawing,withdrawn}`은 기간 조건이 없고, 해당 상태가 없으면 0입니다. A30/A31은 Prometheus 시계열 조회이며 A28/A29의 DB 누적 통계와 구분합니다.
