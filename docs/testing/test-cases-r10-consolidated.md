# Sporty v2 R10 통합 테스트 케이스 · 105개

> 기준: 팀 최종 Excel 95개 + 개인 v0.5 11종 중 정상 탈퇴 1종을 기존 TC-INT-09에 합침 + 신규 고유 시나리오 10개. 2026-11-03.
> 이 문서는 테스트 정의 및 기존 실행 보고서의 판정을 통합해 보여줍니다. 이번 문서 작성 중 105개 테스트를 재실행하지 않았습니다.

## 판정과 중복 정리

| 구분 | 수량 | 처리 |
| --- | ---: | --- |
| 팀 Excel 원본 | 95 | TC ID·요구·사전조건·절차·입력·기대값·실행 기록을 보존. 최신 R10과 충돌하는 일부 기대값만 보정 |
| 개인 11종 | 11 | TC-SAGA-001은 TC-INT-09에 통합. 나머지 고유 10종을 추가 |
| 최종 고유 TC | 105 | 기존 실행 보고서 기준 Pass 10 / Fail 1 / 원본 Not Run 94 |

**중복 매핑:** `TC-SAGA-001` 정상 탈퇴의 HTTP·Saga·매치·참가 정리는 `TC-INT-09`의 동일 판정 목적과 합쳤습니다. 원래 ID는 별칭으로 남겨 기존 실행 보고서와 연결합니다. 다른 10종은 단일 API·서비스 검증과 호출 경로가 일부 같더라도, 비동기 최종 상태·포인트·장애 복구 또는 시계열 관측의 독립적인 합격 조건이 있어 유지했습니다.

**기존 보고서 기준:** [R10 v0.5 최종 실행 보고서](r10-v05-execution-report.md)는 11종 Pass 10, Fail 1을 기록했습니다. 원시 증빙은 저장소 바깥의 로컬 경로를 가리켜 GitHub만으로 재현할 수 없습니다. 이번 통합에서 그 보고서 판정을 연결했으며 94개 원본 Not Run을 임의로 Pass 처리하지 않았습니다. `TC-SAGA-003`은 TIMED_OUT/ACTIVE 이후 늦은 CLEANED로 매치가 CANCELLED인 정합성 결함이므로 Fail을 유지합니다.

**계약 재확인:** Excel의 일부 항목은 `identity-service`, 탈퇴 204, 생성·참가 201, 4서비스 등 과거 기준입니다. 해당 행의 이름·R10 기대값을 보정했습니다. [API 계약 v1.0](../contracts/api-spec-v1.0.md)의 A9/A14 201과 최소 정원 1은 R10 이후 변경 전 설명이므로 실행 시 최신 승인 계약·백엔드 설정과 대조하십시오. 응답 코드·오류 코드가 확정되지 않은 기존 행은 원문을 남기고 실제 명세 확인 전 Pass 판정을 금지합니다.

## 실행·결함 관리

- Not Run: 미실행. Pass: 해당 TC의 HTTP·비동기·DB·이벤트·관측을 실제 대조하고 환경/SHA/증빙을 기록. Fail: 기대값 위반, 결함 URL과 재현 절차를 기록. Blocked: 환경·계측·권한 등 차단 이유와 재시험 계획을 기록.
- 기존 보고서의 Pass 10 / Fail 1은 당시 환경의 기록입니다. 다른 코드 조합에서의 회귀 검증을 뜻하지 않습니다. 세부 자료는 [최종 실행 보고서](r10-v05-execution-report.md)와 [모니터링 검증 기록](r10-v05-monitoring-validation.md)을 참고합니다.
- TC-SAGA-003은 Fail을 유지하고 정합성 수정·재실행 전 전체 통과로 보고하지 않습니다. 원본 Excel 95개 중 다른 94개는 Not Run입니다.
- 회원·매치·포인트·알림 케이스가 같은 요청을 재사용하면 requestId/eventId, 테스트 환경/SHA, 원장·이벤트 증거를 서로 연결하고 확인하지 않은 분기를 중복 Pass로 기록하지 않습니다.
